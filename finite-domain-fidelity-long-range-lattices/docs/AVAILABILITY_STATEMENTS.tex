\subsection*{Data availability}
The numerical data supporting the findings of this study are available in the public GitHub repository at \url{https://github.com/ozalloum/finite-domain-fidelity-long-range-lattices}, release \texttt{v1.0.0}. The repository includes the source data underlying the main figures, combined and panel-level CSV files, processed deterministic and stochastic results, convergence and validation outputs, and representative raw and audit data. Additional numerical results reported in the manuscript and supplementary material can be reproduced using the supplied source code and computational workflow.

\subsection*{Code availability}
The Python source code and computational workflow used in this study are available in the public GitHub repository at \url{https://github.com/ozalloum/finite-domain-fidelity-long-range-lattices}, release \texttt{v1.0.0}. The repository includes scripts for the theoretical, static, and dynamic calculations; numerical validation routines; the paired stochastic pilot; figure-generation scripts; reproducibility tests; and software requirements. The supplied documentation provides the instructions required to reproduce the principal numerical results and regenerate the submitted figures.
