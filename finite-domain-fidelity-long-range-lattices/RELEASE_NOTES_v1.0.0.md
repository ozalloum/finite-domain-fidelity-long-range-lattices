# Release notes - v1.0.0

Initial public computational release for *Fidelity Horizons in Modulationally Unstable Long-Range Nonlinear Lattices*.

## Included

- Core long-range DNLS model implementation.
- Exact-periodized and open/corrected finite-domain operators.
- Theory/static, deterministic dynamic, validation, and paired stochastic-pilot scripts.
- Bundled deterministic and pilot stochastic numerical data.
- Source CSV files for all data-bearing figure panels.
- Publication figures in vector PDF format; redundant PNG copies are intentionally omitted.
- Independent reproducibility smoke test.
- Environment and dependency specifications.
- Result provenance and repository checksum manifests.

## Scientific scope

The deterministic study is the primary evidence. The `R=64` paired stochastic calculation is a pilot and is not a converged rare-event study.

## Archival note

A persistent archive DOI is intentionally not assigned in this prepared GitHub release. If the associated paper is accepted, freeze the accepted computational release and archive that release with a persistent DOI before updating citation metadata.
