# Figure source data

This directory contains the machine-readable source data for all eight main manuscript figures.

- `figure01.csv` through `figure08.csv` are the combined source tables used by the figure-generation workflow.
- `figureXX_panel_*.csv` files provide panel/source-view level exports for every data-bearing plot.
- Figure 1(a) is a geometric lattice schematic rather than a numerical data plot, so it has no empirical/numerical CSV; Figure 1(b) is provided as `figure01_panel_kernel.csv`.
- Figure 6 uses one tidy combined propagation-map table and additionally provides explicit source CSVs for panels (a)-(d): reference intensity, open intensity, corrected intensity, and absolute open-minus-reference intensity error.

All figure files are regenerated by `scripts/make_figures.py`; panel/source-view CSVs are regenerated by `scripts/export_panel_csvs.py`. Ordinary scientific plots are title-free, with scientific context carried by panel labels, axes, legends, and manuscript captions.
